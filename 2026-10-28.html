Node.js Brotli bug CVE-2026-111497 is now actively exploited — check your Node version

dev.to
This post is written as a SillyTavern checklist, but the key part is about Node.js itself. A Node security patch shipped on 2026-10-21, CISA added the bug to its list of actively exploited vulnerabilities on 2026-10-27, and the author says some official Docker images still ship an unpatched Node as of today. Why it matters: every Node.js backend and CI runner you own needs a version check this week. Base images that pin latest may still be unpatched.
