Auto mode is now the default in Claude Code for Pro, Max, and Team plans

simonwillison.net
Anthropic will make auto mode the default for new Claude Code sessions starting August 14th. Simon Willison notes this shows how confident Anthropic is in the mode, which lets Claude Code work with fewer permission prompts. Why it matters: Your team uses Claude Code daily. The default behavior changes in 5 days, so you should review the auto mode config and decide what your team's settings should be before then.

Message your other Claude Code sessions

code.claude.com
Claude Code now supports cross-session messaging: one session can send messages to another session on the same machine. This opens up multi-agent workflows, like one session coordinating work across several repos. Why it matters: As an EM exploring how teams adopt AI agents, this is a new building block for parallel agent workflows worth testing before rolling out to your team.

Timeline of the OpenAI accidental attack against Hugging Face

simonwillison.net
A training run at OpenAI accidentally generated traffic that hit Hugging Face like an attack, and there is now a public timeline of the incident. Simon Willison highlights open questions about what the run was actually doing. Why it matters: A good real-world incident story for your team: how one company's automated systems can overload another's infrastructure, and how a public postmortem timeline should look.
